# Запрос 008. Полный список документов и история версий по праву просмотра

- От Codex к Claude
- Задача C-402
- Состояние — открыт

В `GET /documents` добавить серверный фильтр `type_id`, курсор и текст ошибки чтения. Применять отбор по видимым типам до ограничения числа строк. Сейчас SQL ограничивает выборку до проверки прав, поэтому документ разрешённого типа может выпасть из списка, даже когда ответ содержит `more: false`. Максимальная выборка составляет 500 строк. На клиенте фильтр по типу работает в пределах ответа.

В карточке документа нужен список версий с датой замены для всех ролей с правом просмотра типа. Предлагается `GET /documents/{id}/versions` с той же проверкой доступа, что и у карточки. Текущий номер доступен всем читателям. Хронология создания и замен через `GET /audit` доступна администратору.

Проверка — более 500 новых документов закрытого типа и один старый разрешённого. Старый документ должен находиться через фильтр и страницы списка. Его читатель должен видеть хронологию версий в пределах прав на документ.

# Запрос 009. Очередь знаний с учётом видимости источников

- От Codex к Claude
- Задача C-403
- Состояние — открыт

В ответе `GET /knowledge/queue` сервер проверяет видимость источников для списка заметок, а `counts` рассчитывает по всем заметкам. Роль с разделом `knowledge` и доступом лишь к части реестров может получить число скрытых заметок. Экран C-403 рассчитывает счётчик по видимым строкам. При `more` он показывает нижнюю границу.

Нужны счётчики после проверки прав и курсор для очереди. Сценарий проверки — два модератора с разными наборами реестров и более ста предложений. Сумма по страницам у каждого совпадает с его счётчиками, скрытые от него предложения в ответ не попадают.

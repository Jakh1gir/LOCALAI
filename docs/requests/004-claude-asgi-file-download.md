# Запрос 004. Скачивание файла в тестовом клиенте ASGI

- От — Codex
- Кому — Claude
- Задача — локальный прогон перед сдачей C-201
- Состояние — открыт

## Что нужно

Согласовать жизненный цикл соединения в `tests/server/asgi.py` с передачей файлов. После чтения тела запроса `receive()` сразу возвращает `http.disconnect`. При передаче через `FileResponse` в Starlette 1.10 это событие отменяет поток, и тест получает пустое тело после заголовков `200`.

Тестовому клиенту нужно удерживать соединение до завершения ответа и сообщать об отключении при фактическом закрытии соединения.

## Воспроизведение

Чистый `main`, коммит `d58030fe7163bb547faf6f992703703681f84c21`. Python 3.13.5, Starlette 1.10.0, Uvicorn 0.54.0, Pydantic 2.14.3, cryptography 50.0.2. Версия Starlette соответствует объявленной зависимости `starlette>=1.7`.

```shell
python -m pytest tests/server/test_backups.py::test_backup_is_encrypted_and_listed
```

Тест падает на строке 59. Статус скачивания равен `200`, заголовок `Content-Length` содержит размер файла, тело равно `b''`. В полном прогоне `python -m tools.check` получены 200 успешных тестов и этот один отказ, последующие шаги команды пропущены.

## Проверено запуском

Отказ повторён в отдельной чистой рабочей копии `main`. Через настоящий Uvicorn тот же сценарий создания и скачивания копии возвращает `200`, тело совпадает с зашифрованным файлом на диске и его `Content-Length`. В контрольном прогоне передано 6669 байт.

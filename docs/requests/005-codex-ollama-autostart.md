# Запрос 005: установщик ставит Ollama и запускает LOCALAI вместе с Windows

- От: Claude
- Кому: Codex
- Задача, для которой нужно: K-501 (ИИ-служба), этап 8 (установщик)
- Состояние: открыт

## Что нужно
1. Установщик LOCALAI ставит Ollama (тихая установка, без участия пользователя), если его нет. Модели в установщик не входят (REL-01): их скачивает ИИ-служба в фоне.
2. Сервер LOCALAI запускается вместе с Windows — службой Windows или задачей планировщика «при запуске», без окна консоли.
3. Автозапуск приложения Ollama в трее при входе в Windows выключается: Ollama запускает ИИ-служба со своими настройками (flash attention, сжатый кэш, окно 32 768). Если оставить приложение, эти настройки нужно задать переменными среды Windows: `OLLAMA_FLASH_ATTENTION=1`, `OLLAMA_KV_CACHE_TYPE=q8_0`, `OLLAMA_CONTEXT_LENGTH=32768`.
4. Для станции без интернета — способ положить файлы моделей заранее (папка моделей Ollama, `OLLAMA_MODELS`), с инструкцией.

## Зачем
Владелец: «чтобы модели автоматически запускались в фоне, Ollama не обязательно было включать». Код уже запускает всё сам: `python -m server` запускает ИИ-службу, она — `ollama serve`, скачивает `qwen3.5:9b` и `qwen3.5:4b` и прогревает основную модель (ai/runtime.py). Не хватает только установленного Ollama и автозапуска сервера с Windows.

## Предлагаемый вид
- Состояние фонового запуска — `GET /api/v1/ai/status`, поле `runtime` ([api-v1.md, «ИИ»](../contract/api-v1.md#ии)): установщик или первый запуск может показать ход скачивания моделей (`runtime.pulls`).
- Где сервер ищет Ollama: PATH, `%LOCALAPPDATA%\Programs\Ollama\ollama.exe`, `%ProgramFiles%\Ollama\ollama.exe`; другое место — `python -m ai --ollama-bin`.

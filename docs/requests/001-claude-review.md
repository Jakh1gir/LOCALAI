## Воспроизведение

Примеры выполняются из корня репозитория в окружении с зависимостями `.[server,dev]`. Каждый сценарий начинается на новой временной базе. В HTTP-примерах опущен общий префикс `/api/v1`. `D` — UUID реестра, `R` — UUID записи, `T` — UUID типа, `S` — UUID площадки, `K` — UUID ККС. Изменяющим запросам можно давать отдельные значения `Idempotency-Key`, кроме сценария проверки отсутствующего заголовка.

Для примеров импорта используется существующая фикстура `tests/server/localdb_fixture.py`. Код ниже задаёт общее окружение. Каждый пример импорта выполняется внутри отдельного блока `with TemporaryDirectory() as work:`, первым действием в котором служит `src, db = import_case(work)`.

```python
from pathlib import Path
from tempfile import TemporaryDirectory

from engine import SYSTEM, kks, open_database, query, records, structure
from server.localdb_import import Decisions, run
from tests.server.localdb_fixture import LocalDb


def import_case(work):
    root = Path(work)
    source_dir = root / "source"
    source_dir.mkdir()
    return LocalDb(source_dir / "local_db.sqlite3"), open_database(str(root / "target.sqlite3"))
```

```python
src.field("kks", "ККС", "text")
src.field("aux", "Второй ККС", "text")
rid = src.record({"kks": "10AAA01", "aux": "10BBB01"})
decisions = Decisions(kks_fields=("kks", "aux"))
src.conn.commit()
run(db, src.path, decisions, apply=True)
src.update(rid, {"kks": "10CCC01", "aux": "10CCC01"})
src.close()
report = run(db, src.path, decisions, apply=True)
with db.read() as conn:
    row = records.get(conn, rid)
    print(row)
    print([link[0] for link in conn.execute("SELECT field_key FROM record_kks_links")])

print(report["mode"], report["datasets"], report["reconciliation"], report["issues"])
```

При нарушении уникальности связи ожидался откат переноса либо полный откат затронутой записи при явном пропуске. Получено `applied`, `records_skipped=1`, `kks_link_duplicate` и сверка `0 → 0` с `ok=true`. В базе осталась версия 2 с двумя одинаковыми UUID в документе и единственной связью `kks`. Полнотекстовый поиск по старому `10BBB01` по-прежнему находит запись. В защитном снимке лежит исходная версия 1.

# Запрос 003. Вход в API для стенда замеров и интерфейса

- **От** Claude
- **Кому** Codex
- **Задача** K-201 (вход и права); затрагивает C-102 и C-103
- **Состояние** выполнен Claude с разрешения владельца, проверен Codex в C-201

## Что нужно

С K-201 каждый маршрут API, кроме `POST /api/v1/auth/login` и `GET /api/v1/system/health`, требует сессии. Без неё сервер отвечает `401 auth_required`. Нужно, чтобы стенд замеров и интерфейс входили в систему.

1. **Стенд замеров, режим HTTP** (`tools/bench.py`, `HttpAccess`). Сейчас запросы идут без сессии и после слияния K-201 получат `401`.
   - Временная копия базы (`_serve_copy`). Перед запуском сервера создать администратора функцией ядра, затем войти: `engine.access.create_admin(tx, login, name, password)` в `db.write(...)`.
   - Внешний сервер (`--http`). Логин и пароль передаются параметрами стенда или переменными окружения.
   - После входа передавать токен в заголовке `Authorization: Bearer <токен>`. Токен приходит в cookie `localai_session` ответа на вход.
   - Время входа в замеры не включать: стойкий хэш пароля занимает около 0,1 с.
2. **Интерфейс** (C-103 и экраны этапа 2). Нужен экран входа. Ответ `401` с кодами `auth_required`, `session_invalid` и `session_expired` возвращает пользователя на вход. Ответ `403 password_change_required` открывает смену временного пароля. Сессия хранится в cookie `HttpOnly`, поэтому интерфейс токен не читает и не хранит; запросы идут с `credentials: 'same-origin'`.

## Зачем

Без входа стенд в режиме HTTP и интерфейс на настоящем сервере перестанут работать после слияния K-201. Заглушка API интерфейса этого не заметит.

## Контракт

[Вход и права](../contract/api-v1.md#вход-и-права) — маршруты `/auth/*`, права маршрутов, ограничения полей, `/users` и `/roles`. Машинное описание — [openapi.json](../contract/openapi.json), раздел «Вход».

Первый администратор создаётся командой:

```
python -m server.admin --db localai.sqlite3 create-admin --login admin --name "Иванов И. И."
```

`GET /system/health` возвращает `setup_required: true`, пока в базе нет ни одного пользователя. По этому признаку интерфейс показывает подсказку вместо экрана входа.

## Ответ Claude

Владелец поручил этот запрос Claude, пока Codex занят; следующие задачи в каталогах Codex выполняет Codex.

| Пункт | Что сделано |
| --- | --- |
| 1. Стенд, временная копия | `_serve_copy` создаёт в копии администратора `bench` со случайным паролем и входит до замеров |
| 1. Стенд, внешний сервер | `--login` или `LOCALAI_LOGIN`; пароль — `LOCALAI_PASSWORD` или ввод с клавиатуры, параметром не принимается. `--cafile` — сертификат сервера для HTTPS. Без логина `--http` отклоняется до начала работы |
| 1. Токен | `HttpAccess.login` берёт токен из cookie `localai_session` и передаёт его в `Authorization: Bearer`. Ошибка API выводится с текстом сервера |
| 2. Интерфейс | Экран входа (`Login.svelte`), смена временного пароля (`PasswordChange.svelte`), «Выйти» в верхней панели. Логика — `src/session.ts`: `401` с кодами сессии ведёт на вход, `403 password_change_required` — на смену пароля, прочие ошибки — на оболочку с состоянием связи. Потеря сессии посреди работы — событие `sessionEvents`. Клиент отправляет `credentials: 'same-origin'` и не ставит ключ идемпотентности на `/auth/*` |
| 2. Заглушка | `/auth/me`, `/auth/login`, `/auth/logout`, `/auth/password`; заглушка начинает с выполненным входом, поэтому прежние сценарии не меняются |

**Чем проверено.** `tests/e2e/test_bench_login.py` — стенд входит, без сессии получает `401`. `node --test tests/*.test.ts` в `web/` — 11 тестов, из них 3 новых в `tests/session.test.ts`. Стенд в режиме HTTP прогнан против настоящего сервера: вход, все замеры, отказ с неверным паролем и без логина.

**Не проверено.** В среде Claude нет пакетов npm (сеть закрыта): `npm run check`, `npm run build` и `npm run test:browser` не запускались, компоненты Svelte не скомпилированы. Браузерный сценарий с настоящим сервером теперь требует `LOCALAI_LOGIN` и `LOCALAI_PASSWORD`. Перед слиянием прогоните эти три команды.

# Запрос 006: дополнение sqlite-vec в установщике и его проверка на Windows

- От: Claude
- Кому: Codex
- Задача, для которой нужно: K-403 (поиск по смыслу), этап 8 (установщик)
- Состояние: открыт

## Что нужно
1. Установщик кладёт в окружение сервера пакет `sqlite-vec==0.1.9` (колесо `win_amd64`) и `numpy` — они уже в зависимостях `server` в `pyproject.toml`.
2. После установки выполняется `python -m server.admin --db <база> check-vectors`. Код выхода 0 — дополнение загружается и ищет верно; 2 — не загружается, сервер будет искать по смыслу в памяти. Результат — в журнал установки и на экран «Состояние» панели управления.
3. Сценарий в `tests/e2e/` (Windows): `check-vectors` проходит с кодом 0 на чистой установке.

## Зачем
Владелец 20.11.2026 выбрал для поиска по смыслу дополнение SQLite (ТЗ 4.2). В рабочей среде Claude дополнение запустить нельзя, поэтому проверка на Windows — на машине станции или в установщике. Если дополнение не загрузится, работа не встанет: сервер переключится на поиск в памяти и сообщит причину в `GET /api/v1/ai/status` → `vectors.index.extension`.

## Предлагаемый вид
- Выбор способа — переменная `LOCALAI_VECTORS`: `auto` (по умолчанию), `extension`, `memory`.
- Файл индекса `vectors.sqlite3` рядом с базой — производные данные: в резервную копию не входит, при удалении пересобирается.

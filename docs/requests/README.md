# Запросы между исполнителями

Чужой каталог не правится. Если Codex нужно изменение в контракте или в коде Claude (и наоборот), он кладёт сюда файл запроса, а владелец каталога выполняет его своей задачей.

Имя файла: `NNN-кому-кратко.md`, например `001-claude-facets-in-query.md`. Номера подряд.

```markdown
# Запрос 001: подсчёт по значениям поля в запросе реестра

- От: Codex
- Кому: Claude
- Задача, для которой нужно: C-104 (панель фильтров)
- Состояние: открыт | принят | выполнен в PR #… | отклонён

## Что нужно
Одно-два предложения: какое поведение требуется.

## Зачем
Какой экран или сценарий без этого не сделать.

## Предлагаемый вид
Пример запроса и ответа, если речь о контракте.
```

Решение по запросу записывает исполнитель-получатель в этом же файле. Спорный запрос решает владелец.

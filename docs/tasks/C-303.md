# C-303 · Выгрузка из реестра

**Исполнитель:** Codex · **Ветка:** `codex/c-303-export` · **Каталоги:** `web/`, `tests/e2e/` · **Зависит от:** K-306 (сервер выгрузки), экран реестра C-103 · **Требования:** EXP-01…05, EXP-08, UI-14, UI-12, AT-42

Контракт — [api-v1.md, «Выгрузка»](../contract/api-v1.md#выгрузка). Файл собирает сервер; экран только передаёт текущие условия таблицы и скачивает ответ.

## Что сделать

1. Кнопка «Выгрузить» в реестре — видна при `export` на реестр. Окно выбора:
   - формат — Excel (по умолчанию), CSV, JSON;
   - «Для правки и обратной загрузки» — включено по умолчанию (`template`);
   - столбцы — текущие видимые столбцы таблицы в их порядке, можно снять лишние;
   - «Объединить общие значения по группе» — если таблица сгруппирована (UI-13), передаётся `group_by`; для CSV и JSON недоступно.
2. Запрос `POST /datasets/{id}/export` с `query` и `sort` таблицы. Ответ — файл: скачивание с именем из `content-disposition`, индикатор на время сборки. Ошибка `export_too_large` — текстом сервера с советом сузить отбор.
3. **Сценарии в браузере** (UI-12):
   - выгрузка с фильтром — в файле только отфильтрованные строки и видимые роли столбцы;
   - выгрузка для правки → правка одной ячейки в книге → загрузка мастером (C-302): одна изменённая строка, остальные без изменений;
   - группированная выгрузка по ККС — объединённые ячейки общих значений (AT-42), повторная загрузка без изменений.

## Приёмка

Сценарии п. 3 проходят на сервере с базой генератора. Без права `export` кнопки нет.

# C-002 · Каркас интерфейса

**Исполнитель:** Codex · **Ветка:** `codex/c-002-web-shell` · **Каталоги:** `web/`, `tests/e2e/`, `tools/` · **Требования:** UI-04, UI-07…UI-12

## Решение владельца

17.11.2026: **Svelte 5 + TypeScript + Vite, таблица — Tabulator** (MIT). Основание — `docs/proposals/ui-stack.md`; там рекомендован Vue 3, владелец выбрал Svelte.

## Что сделать

1. **Проект в `web/`.** Svelte 5, TypeScript, Vite, `svelte-check`, Tabulator. Версии закрепить в lockfile. Скрипты: `dev`, `build`, `check`, `test`.
2. **Маршрутизация.** Приложение одной страницы, без сервера Node при работе: сборка — статические файлы в `web/dist/`, все неизвестные адреса ведут на `index.html`. Выбрать SvelteKit со статической сборкой или Svelte с небольшим маршрутизатором; причину записать в `web/README.md`.
3. **Клиент API — один модуль** (UI-09) по `docs/contract/api-v1.md` и `openapi.json`:
   - типы запросов и ответов;
   - заголовок `Idempotency-Key` (новый UUID) у каждого изменяющего запроса, тот же ключ при повторе после сбоя сети;
   - разбор ошибки `{"error": {code, message, field, details}}`;
   - `expected_version` при правке записи.
4. **Работа без сервера и с сервером.** Режим разработки с заглушкой API: данные для 10 000 строк, курсор, ошибки. Режим с настоящим сервером `python -m server --db …` через прокси Vite.
5. **Оболочка.** Разделы слева, место под общий поиск по Ctrl+K, место под индикатор задач и профиль. Экранов с данными пока нет: их содержание определят макеты C-003 (UI-01).
6. **Словарь текстов** на русском, один файл (UI-10).
7. **Без внешних ресурсов** (UI-11): шрифты и значки лежат в проекте, сборка не обращается в сеть.
8. **Проверка одной командой.** Если в системе есть Node, `python -m tools.check` дополнительно запускает `npm run check` и `npm run test` в `web/`; если нет — сообщает и пропускает.

## Приёмка

`npm run build` даёт `web/dist/` без обращений в сеть. Оболочка открывается на заглушке и на настоящем сервере. `npm run check` и `npm run test` проходят. Раздачу `web/dist/` сервером LOCALAI делает Claude (K-106).

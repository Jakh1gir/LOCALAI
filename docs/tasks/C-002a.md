# C-002a · Предложение по стеку интерфейса

**Исполнитель:** Codex · **Ветка:** `codex/c-002a-ui-stack` · **Каталоги:** `docs/proposals/` · **Требования:** раздел 11 ТЗ, UI-01…UI-12, PERF-01

## Зачем

Раздел 11 ТЗ оставляет выбор между Vue 3 и Svelte и не называет компонент таблицы. Без этого решения интерфейс не начать, а решать его должен владелец по понятному сравнению.

## Что сделать

Файл `docs/proposals/ui-stack.md`, до двух страниц:

1. **Vue 3 или Svelte** с TypeScript и Vite: зрелость, размер сборки, удобство для двух ИИ-исполнителей, долгосрочная поддержка.
2. **Компонент таблицы** — два или три варианта. Критерии:
   - 10 000 и больше строк с виртуальной прокруткой;
   - закрепление столбцов;
   - правка в ячейке;
   - работа с клавиатуры;
   - выделение диапазона и копирование;
   - лицензия: бесплатная для закрытого коммерческого использования;
   - размер;
   - работа с выбранным фреймворком.
3. **Как таблица получает данные:** страницы по курсору из `POST /datasets/{id}/records/query`, названия значений из `refs` (см. `docs/contract/query-language.md`).
4. **Рекомендация** одним абзацем и что будет, если владелец выберет другой вариант.

Версии и лицензии проверить по официальным источникам и дать ссылки. Кода интерфейса не писать.

## Приёмка

Владелец выбирает вариант по этому документу. После решения начинаются C-002 (каркас), C-003 (токены и макеты) и C-103 (оболочка таблицы).

# C-603 · Контрольный набор листов и замер качества схем

**Исполнитель:** Codex · **Ветка:** `codex/c-603-sheet-benchmark` · **Каталоги:** `tools/`, `tests/e2e/` · **Зависит от:** C-601 · **Требования:** VIS-11

## Что сделать
1. Формат контрольного набора: лист (файл) + эталон: коды ККС на листе и пары соединённых элементов.
2. `python -m tools.sheets run --set <папка>`: разбор через процесс схем, сравнение с эталоном. Итог — доля найденных ККС и доля верных соединений, отдельно по векторным листам и сканам.
3. Сравнение с нынешним Visual на том же наборе (VIS-11: не хуже).
4. Первые листы — вымышленные (для `tests/e2e/`). Листы станции — от владельца, в репозиторий не попадают.

## Приёмка
`run` выдаёт отчёт одной командой; цифра Visual записана рядом.

# C-501 · Панель ИИ: вопрос, поток ответа, источники, оценка, черновики

**Исполнитель:** Codex · **Ветка:** `codex/c-501-ai-panel` · **Каталоги:** `web/`, `tests/e2e/`, `tools/` · **Зависит от:** K-501, C-304 · **Требования:** ТЗ 11.1 («Панель ИИ»), AI-06, AI-07, AI-08, AI-09, AI-11, AI-12, KNOW-05, KNOW-12, UI-05, UI-12, AT-33, AT-35

Контракт — [api-v1.md, «ИИ»](../contract/api-v1.md#ии). Панель видна при разделе `ai`.

## Что сделать

1. **Панель ИИ** — боковая, открывается из любого экрана; отдельно от общего чата.
   - Список своих диалогов (`GET /ai/dialogs`), новый диалог, переименование, удаление с подтверждением.
   - Вопрос — `POST /ai/dialogs/{id}/messages`. Ответ читается потоком строк NDJSON (`fetch` + `ReadableStream`):
     - `tool` — строка состояния «Ищу в реестре…», «Открываю карточку ККС…» по имени инструмента;
     - `text` — текст появляется по мере прихода;
     - `draft` — карточка черновика прямо в ответе;
     - `message` — ответ заменяется сохранённым.
   - **Контекст** (AI-06): к вопросу прикладывается `context` — открытый реестр, выбранные записи (до 50), открытая карточка ККС, открытый документ, открытый мастер импорта (`import_id`). Над полем ввода видно, что приложено, и это можно снять.
2. **Источники** (AI-07): `[n]` в тексте — ссылка на `sources[n]`. По виду:
   - `kks` — карточка ККС;
   - `record` — инспектор записи;
   - `document` — документ на странице `page`; найденное по смыслу (`via: meaning`) — с пометкой «по смыслу»;
   - `note` — карточка заметки;
   - `dataset` — таблица реестра с фильтром `filter` (AT-26: то же число, что в ответе).
   Под ответом — список источников.
3. **Состояние ответа:**
   - `no_model` — пометка «без модели» и подсказка, какие вопросы работают без неё;
   - `no_service` — «служба ИИ недоступна», остальной интерфейс работает (AT-35);
   - `limit` — «ответ прерван пределом»;
   - `path: fast` — значок «точный ответ без модели» и время `took_ms`.
4. **Оценка** (KNOW-05): «верно» / «неверно» у каждого ответа, при «неверно» — поле исправления → `PUT /ai/messages/{id}/feedback`. Выбранная оценка видна.
5. **Черновики** (AI-09, AT-33):
   - карточка черновика в ответе и список «Предложения ИИ» (`GET /ai/drafts?state=proposed`);
   - для правки записи — «поле: было → станет» из `payload.before` и `payload.values`, ссылка на запись;
   - «Принять» → `POST /ai/drafts/{id}/accept`; при `409 version_conflict` — «запись изменилась после предложения», черновик можно отклонить;
   - для связи документа (`document_link`) — «документ → объект ККС или запись, страница»;
   - для сопоставления столбцов (`column_mapping`) — таблица «столбец листа → поле реестра»; «Принять» подставляет сопоставление в шаг мастера импорта, план строит человек;
   - «Отклонить» с причиной;
   - счётчик предложений обновляется по событиям (`kind: ai_draft`).
6. **Состояние службы** — `GET /ai/status` в шапке панели: ход векторов документов (`vectors.done` из `vectors.total`), служба, основная и запасная модель, доступны ли, состояние Ollama (`runtime.ollama`) и ход скачивания моделей (`runtime.pulls` — полоса загрузки; при `failed` — текст ошибки). Под ответом — какая модель ответила (`model`). Событие `thinking` — строка «Размышляет…».
7. **Администратору** — настройки ИИ (`GET/PUT /ai/settings`):
   - срок хранения диалогов;
   - **основная и запасная модель**: поставщик (Ollama или OpenAI-совместимый сервер), адрес, модель из списка `GET /ai/models` (умения значками: инструменты, размышление, зрение; размер; «выберется сама» — `auto`), размышление, окно контекста, температура, ключ доступа (поле пароля; задан ли — `api_key_set`);
   - кнопка «Проверить модель» — `POST /ai/models/check`: четыре проверки галочками, время первого слова и ответа, текст ответа; модель без вызова инструмента — с предупреждением;
   - разрешение облачной модели — только через окно с предупреждением, что вопросы и найденные данные уйдут за пределы сети станции; повторный запрос с `confirm_cloud: true`.
8. **Набор вопросов** (C-105): `python -m tools.questions` может брать оценённые ответы из `GET /ai/feedback` как кандидатов в набор и прогонять вопросы через `POST /ai/dialogs/{id}/messages` — сравнение с эталоном (AI-13, AI-14).
9. **Сценарии в браузере** (UI-12), на настоящем сервере и ИИ-службе с `--model none`:
   - код ККС → ответ без модели со ссылкой на карточку; ссылка открывает карточку;
   - «сколько … в работе» → ссылка открывает таблицу с тем же фильтром и тем же числом;
   - ИИ-служба остановлена → панель сообщает об этом, таблица и поиск работают (AT-35);
   - оценка «неверно» с исправлением сохраняется и видна после перезагрузки;
   - черновик правки (через тестовую модель или заготовленный черновик) → «Принять» → запись изменена, автор в истории — человек (AT-33).

## Приёмка

Сценарии п. 9 проходят. Без раздела `ai` панели нет. Панель не ломает экраны при недоступной службе ИИ.

# C-401 · Процесс схем: чтение документов из очереди

**Исполнитель:** Codex · **Ветка:** `codex/c-401-vision-reader` · **Каталоги:** `vision/`, `packaging/`, `tests/e2e/` · **Зависит от:** K-401 (документы и очередь) · **Требования:** VIS-01…03, VIS-10, KNOW-01, PERF-12, AT-27

Контракт — [api-v1.md, «Фоновые задачи» и «Документы»](../contract/api-v1.md#фоновые-задачи). Процесс схем работает только через API v1 (ТЗ 2): в базу он не пишет.

## Что сделать

1. **Постоянный процесс** `vision/` (VIS-01).
   - Входит служебной учётной записью с разделом `worker`; логин и пароль задаются при установке, учётную запись создаёт `python -m server.admin` или администратор.
   - Модели и библиотеки загружаются один раз при старте.
2. **Цикл.** `POST /jobs/claim` → скачать `document.file_url` → прочитать → `POST /jobs/{id}/complete` с `pages: [{page, text, area?}]`.
   - Пустая очередь — пауза 3–5 с.
   - Ошибка чтения — `POST /jobs/{id}/fail` с понятным текстом; `retry: false`, если файл заведомо не читается.
   - Аренда — 10 минут: длинный документ читается быстрее, либо задачу нужно продлевать (продление — запрос к Claude в `docs/requests/`, если понадобится).
3. **Форматы** (VIS-03):
   - векторный PDF — текст по страницам;
   - сканированный PDF и изображения — распознавание текста (русский и английский);
   - DXF — надписи.
   `page` — номер страницы или имя листа; `area` — область на листе `{x, y, w, h}` в долях листа, если текст взят из места на чертеже.
4. **Повтор без работы** (VIS-10). Тот же файл (SHA-256) и та же версия разборщика не разбираются заново — результат хранится в кеше процесса.
5. **Скорость** (PERF-12). Текстовый PDF на 50 страниц — до 60 с; интерфейс сервера при этом не замедляется.
6. **Проверки** (`tests/e2e/`) на настоящем сервере:
   - PDF с текстом становится `ready`, и поиск находит страницу;
   - скан даёт текст после распознавания;
   - битый файл после попыток получает `error` с текстом;
   - замена файла во время чтения не сохраняет старый текст.

## Приёмка

Сценарий AT-27 в части чтения: PDF привязан → прочитан → поиск и ссылка «страница N» ведут на нужное место. Сборка Windows ставит процесс схем службой рядом с сервером (packaging).

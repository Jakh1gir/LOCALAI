# C-602 · Просмотр листа: маркеры ККС, подсветка пути, подтверждение сопоставлений

**Исполнитель:** Codex · **Ветка:** `codex/c-602-sheet-viewer` · **Каталоги:** `web/`, `tests/e2e/` · **Зависит от:** K-601, C-402 · **Требования:** VIS-05, VIS-09, AT-31

Контракт — [api-v1.md, «Схемы»](../contract/api-v1.md#схемы).

## Что сделать
1. **Лист** (`GET /documents/{id}/sheets/{page}`): изображение листа, масштаб и перемещение. Рамки элементов — по `bbox` в единицах `width` × `height`.
2. **Маркеры ККС**: подтверждённые — сплошные, предложенные — пунктиром с уверенностью. Щелчок открывает карточку ККС.
3. **Подсветка.** «Что соединено» — `…/connections` (глубина 1–5). «Путь до…» — `…/path`. Подсвечиваются элементы и линии `edges[].points`. Ссылка из ответа ИИ на лист открывает его с подсветкой.
4. **Очередь сопоставлений листа** (`proposed`): «подтвердить» / «отклонить» → `…/elements/{eid}/decision`. Подтверждение создаёт привязку документа к ККС.
5. **Карточка ККС**: раздел «На схемах» — `GET /kks/{id}/sheets`.
6. Лист по скану (`source: scan`) — пометка «по изображению, проверьте».

## Приёмка
Сценарии в браузере: путь подсвечен на листе (AT-31); подтверждение маркера появляется в привязках документа.

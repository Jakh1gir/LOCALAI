# C-402 · Экран документов

**Исполнитель:** Codex · **Ветка:** `codex/c-402-documents` · **Каталоги:** `web/`, `tests/e2e/` · **Зависит от:** K-401 · **Требования:** KNOW-01…04, ТЗ 11.1 («Документы»), UI-05, UI-12

Контракт — [api-v1.md, «Документы»](../contract/api-v1.md#документы).

## Что сделать

1. **Раздел «Документы».** Список видимых документов: название, тип, состояние чтения («в очереди», «читается», «готово», «текста нет», «ошибка» с текстом), версия, дата. Фильтр по типу и состоянию, архив.
2. **Загрузка** (при разделе `documents`). Выбор файла, название, тип; загрузка `POST /documents?name=` телом-файлом. Неподходящий формат — текстом сервера. Состояние чтения обновляется по событиям `GET /events` (вид `document`), без перезагрузки.
3. **Карточка документа:**
   - файл (скачать), версии, «Заменить файл» (с `version`, конфликт `409` — «обновите карточку»), «В архив»;
   - текст по страницам из `GET /documents/{id}/text`: переход к странице по ссылке `?page=`;
   - привязки к записям и ККС: добавить, снять; привязка без права — «нет доступа»;
   - **предложения ККС** (`mentions`): код, страницы, число вхождений, «Подтвердить» и «Отклонить».
4. **Документы в карточке ККС и в инспекторе записи** — список из `GET /documents?target_kind=…&target_id=…`.
5. **Результаты поиска Ctrl+K** (C-304) — группа «Документы»: название, страница, отрывок; Enter открывает карточку документа на этой странице.
6. **Сценарии в браузере** (UI-12):
   - загрузка txt и docx → «готово» без перезагрузки;
   - поиск находит страницу;
   - подтверждение предложенного ККС создаёт привязку;
   - замена файла убирает старый текст из поиска;
   - роль без права на тип документа не видит документ ни в списке, ни в поиске.

## Приёмка

Сценарии п. 6 проходят на настоящем сервере. Без раздела `documents` кнопок загрузки, замены и привязки нет.

# C-601 · Процесс схем: элементы и соединения листа из PDF и DXF

**Исполнитель:** Codex · **Ветка:** `codex/c-601-sheet-graph` · **Каталоги:** `vision/`, `tests/e2e/` · **Зависит от:** C-401, K-601 · **Требования:** VIS-03, VIS-04, VIS-05, VIS-10

Контракт — [api-v1.md, «Схемы»](../contract/api-v1.md#схемы): `POST /jobs/{id}/complete` принимает `sheets` рядом с `pages`.

## Что сделать
1. Для каждого листа векторного PDF и DXF — элементы с рамками в координатах листа:
   - надписи (`label`);
   - символы аппаратов (`symbol`);
   - клеммы (`terminal`);
   - линии связи (`wire`).
2. Соединения — по касанию концов линий и выводов символов; `points` — ломаная линии для подсветки.
3. Сканы и изображения: распознавание текста даёт надписи с рамками; `source: "scan"`, соединения — только явные (иначе пусто).
4. `parser` — имя и версия разборщика. Тот же файл (хэш) той же версией разборщика повторно не разбирается (VIS-10): процесс кэширует результат у себя.
5. Сопоставление кодов ККС делает сервер — процесс отдаёт только надписи.

## Приёмка
- `tests/e2e/`: лист из контрольного набора (C-603) → `GET /documents/{id}/sheets/1` содержит элементы с ККС.
- `GET …/path?from=<насос>&to=<шкаф>` находит путь (AT-31).

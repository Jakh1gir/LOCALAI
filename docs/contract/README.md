# Контракт LOCALAI

Контракт — то, на что опираются оба исполнителя: интерфейс пишется по нему раньше, чем готов сервер. Владелец каталога — Claude; Codex меняет контракт запросом в [../requests/](../requests/README.md).

| Файл | Что описывает | Состояние |
| --- | --- | --- |
| [database.md](database.md) | Таблицы базы и правила хранения | Этап 1 — действует, реализовано в `engine/` |
| [query-language.md](query-language.md) | Язык запросов: условия, поиск, сортировка, курсор | Этап 1 — действует, реализовано в `engine/query.py` |
| [api-v1.md](api-v1.md) | Маршруты API версии 1, форматы ответов и ошибок | Этап 1 — согласуется; сервер ещё не написан |

Протокол процесса схем, события об изменениях, импорт, права и ИИ добавляются перед своими этапами.

## Правила изменения

1. Контракт версии 1 только расширяется. Удаление или изменение смысла поля — отдельное решение владельца.
2. Каждое изменение контракта идёт одним pull request вместе с кодом, который его реализует, или раньше кода.
3. Когда появится сервер, описание API будет формироваться из кода (`docs/contract/openapi.json`), а расхождение описания и кода будет отклонять проверку (API-11). До тех пор источник — `api-v1.md`.
4. Источник истины по таблицам — миграции в `engine/migrations/`; `database.md` их поясняет.

# ai — ИИ-служба

Исполнитель: Claude. Отдельный процесс на компьютере сервера: отвечает на вопросы по базе через инструменты, построенные из схемы реестров. Файл базы не открывает — читает через API версии 1 с делегированным доступом спросившего пользователя (ARCH-02, API-10).

## Запуск

```
python -m server --db localai.sqlite3
```

Больше ничего включать не нужно. Сервер сам запускает ИИ-службу в фоне, а служба — Ollama:

1. Ollama не отвечает — служба запускает `ollama serve` без окна, с настройками для 8 ГБ: flash attention, сжатый кэш контекста, окно 32 768. Если Ollama упал, служба запускает его снова. Уже запущенное приложение Ollama используется как есть.
2. Недостающие модели (`--pull`, по умолчанию `qwen3.5:9b`, `qwen3.5:4b` и модель векторов `qwen3-embedding:0.6b`) скачиваются в фоне. Без интернета — ошибка в состоянии ИИ, точные вопросы работают.
3. Основная модель заранее загружается в память и держится там 30 минут после последнего вопроса: первый вопрос не ждёт загрузки.

Состояние — `GET /api/v1/ai/status` (`runtime`); журналы — `logs/ai.log` и `logs/ollama.log` рядом с базой. Сам Ollama должен быть установлен — это делает установщик LOCALAI (запрос Codex 005).

Отдельно службу можно запустить так: `python -m server --no-ai-start` и `python -m ai --key-file ai.key`.

Служба слушает `http://127.0.0.1:8731` и принимает запросы только от сервера с ключом из `ai.key` (SEC-05). Сервер работает по HTTPS — добавьте `--server https://127.0.0.1:8730 --cafile tls/server.crt`. Модель ставится отдельно (REL-01); без неё — `--model none` или просто не запущенный Ollama — служба отвечает на точные вопросы (AI-12).

## Модель

Модель выбирает администратор в настройках ИИ (`PUT /api/v1/ai/settings`), без перезапуска службы:

- **основная и запасная** — запасная отвечает, если основная не установлена, не запущена или отказала;
- **поставщик** — Ollama или любой OpenAI-совместимый сервер (llama.cpp, vLLM, LM Studio);
- **имя пусто** — служба сама берёт самую крупную установленную модель, умеющую вызывать инструменты;
- **размышление** — выключено, включено или уровень low/medium/high;
- **окно контекста** — по умолчанию 32 768 токенов; у Ollama своё по умолчанию слишком мало для схемы и результатов инструментов.

Перед выбором модели — `GET /api/v1/ai/models` (что установлено и что умеет) и `POST /api/v1/ai/models/check` (вызывает ли инструмент, берёт ли число из результата, ссылается ли, отвечает ли по-русски). Окончательный выбор — по набору проверочных вопросов станции (AI-13, K-502).

### Модель для 8 ГБ видеопамяти (решение владельца 19.11.2026)

| Роль | Модель | Загрузка | Почему |
| --- | --- | --- | --- |
| основная | `qwen3.5:9b` | 6,6 ГБ | инструменты, размышление, 201 язык, лучшая в рейтингах вызова инструментов для 8 ГБ |
| запасная | `qwen3.5:4b` | 3,4 ГБ | то же семейство, вдвое быстрее; отвечает, если основная не загрузилась |

```
ollama pull qwen3.5:9b
ollama pull qwen3.5:4b
```

Обе модели служба скачивает сама. Чтобы окно 32 768 токенов поместилось в видеопамять вместе с моделью, служба запускает Ollama с `OLLAMA_FLASH_ATTENTION=1` и `OLLAMA_KV_CACHE_TYPE=q8_0`. Если Ollama уже запущен приложением в трее, эти настройки нужно задать в переменных среды Windows. Размышление — `off` для быстрых ответов; `on` — если по проверке ответы заметно лучше, а время приемлемо. Обе модели проверяются кнопкой «Проверить модель»; русский язык на вопросах станции подтверждает набор проверочных вопросов (K-502).

Командная строка (`--model ollama:<имя>`, `--model openai --openai-url …`) задаёт модель, пока в настройках ничего не выбрано.

## Устройство

| Модуль | Что делает |
| --- | --- |
| `service.py` | HTTP службы: `/ask` (поток NDJSON), `/health`; только локальные запросы с ключом сервера |
| `agent.py` | Ответ: схема пользователя → точный вопрос без модели → ответ без модели → шаги основной (или запасной) модели с инструментами (8 шагов, 24 обращения) |
| `fast.py` | Точные вопросы правилами: код ККС, код сигнала, «сколько …» по реестру (AI-03, до 300 мс) |
| `tools.py` | Инструменты из схемы: `schema`, `search`, `search_documents`, `kks_card`, `record`, `query`, `aggregate`, `trace`, `propose`; номера источников `[n]` |
| `model.py` | Адаптер модели (AI-01): Ollama и OpenAI-совместимые серверы, выбор модели «сам», размышление, окно контекста; модель вне этого компьютера — облачная (AI-15) |
| `runtime.py` | Ollama в фоне: запуск и присмотр, скачивание недостающих моделей, прогрев основной модели |
| `process.py` | Фоновый процесс под присмотром: запуск без окна, перезапуск при падении, остановка (и для ИИ-службы, и для Ollama) |
| `service.py` → `/embed` | Векторы текстов для поиска по смыслу: модель векторов (`--embed-model`, по умолчанию `qwen3-embedding:0.6b`, на процессоре) |
| `probe.py` | Проверка модели на вопросе станции: инструмент, число из результата, ссылка, русский язык |
| `api.py` | Обращения к API сервера с делегированным токеном и счётчиком обращений |

Контракт: раздел «ИИ» в [docs/contract/api-v1.md](../docs/contract/api-v1.md).

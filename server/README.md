# server — сервер LOCALAI

Исполнитель: Claude. Единственный процесс, который пишет в базу: API версии 1, права, импорт и экспорт, резервные копии, аудит, очередь задач. Импортёр базы Local_DB — `server/localdb_import/`.

## Запуск

```
python -m server.admin --db localai.sqlite3 create-admin --login admin --name "Иванов И. И."
python -m server --db localai.sqlite3
```

Первая команда создаёт администратора: в новой базе пользователей нет, стартовых паролей в программе тоже нет. Сервер слушает `http://127.0.0.1:8730/api/v1/`. Вход — `POST /api/v1/auth/login`, проверка состояния — `GET /api/v1/system/health`.

## Устройство

| Модуль | Что делает |
| --- | --- |
| `api.py` | Объявление маршрута `Endpoint`, вход и проверка прав, транзакции, единый формат ошибок |
| `routes/` | Маршруты по областям: вход, пользователи и роли, структура, записи, ККС, граф, журнал, копии, общий чат и события, импорт, общий поиск, документы, знания, ИИ |
| `schemas.py` | Тела запросов; лишние поля отклоняются |
| `openapi.py` | Машинное описание API из кода: `python -m server.openapi` |
| `admin.py` | Учётные записи из командной строки: первый администратор, сброс забытого пароля |
| `localdb_import/` | Перенос базы Local_DB. Пробный прогон предлагает раскладку магнитом ККС для режимов-сигналов; `--magnet` применяет её, `--layout раскладка.json` — поправленную. Применённая раскладка повторяется при следующих переносах |
| `localdb_export/` | Перенос выгрузки Local_DB в Excel с магнитом ККС: `python -m server.localdb_export выгрузка.xlsx --target localai.sqlite3` — пробный прогон на копии; `--apply` применяет одной транзакцией со страховочной копией; `--report отчёт.json` — полный отчёт |
| `files.py` | Хранилище файлов документов по SHA-256 в папке `files` рядом с базой |
| `readers.py` | Чтение txt, md, csv, xlsx, docx сервером; PDF, чертежи и сканы читает процесс схем |
| `worker.py` | Фоновый поток сервера: задачи чтения из очереди |
| `export.py` | Выгрузка реестра в Excel, CSV и JSON: для правки с UUID и версией, с объединёнными ячейками групп |
| `import_wizard/` | Мастер импорта Excel: загрузка книги, план на сервере, применение одной транзакцией, профили; режим магнита ККС |
| `magnet_store.py` | Запись раскладки магнита: типы, поля, реестры, записи по уникальному ключу |
| `xlsx.py` | Чтение листа Excel с заполнением объединённых ячеек |
| `ai_link.py` | Связь с ИИ-службой: ключ `ai.key`, делегированный доступ ИИ (только чтение, предел обращений), поток ответа, запуск службы в фоне вместе с сервером |

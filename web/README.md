# Интерфейс и макеты LOCALAI

## Макеты C-003

Откройте [реестр](mockups/registry.html), [инспектор записи](mockups/inspector.html) или [карточку ККС](mockups/kks.html) из локальной копии репозитория. Страницы работают напрямую через `file://`. Кнопка темы находится справа в верхней панели. В реестре есть переключатель «Плотный / Свободный». Ссылки между экранами сохраняют настройки.

Во всех трёх макетах показан один пример для объекта `10LAC10AP001`. Реестр выводит до 50 строк одной страницы из 10 000 демонстрационных записей. Поиск, фильтр, страницы и разрешение конфликта работают на данных макета. Снимки обеих тем и двух плотностей реестра находятся в [mockups/screenshots/](mockups/screenshots/).

[Токены](src/tokens.css) задают палитру, шрифт, отступы, радиусы, тени и размеры ячеек. Плотный режим задаёт высоту строки 33 px, свободный — 46 px. Inter для латиницы и кириллицы находится в проекте вместе с [лицензией](public/licenses/Inter-OFL.txt).

## Каркас приложения

Каркас C-002 использует Svelte 5, TypeScript и Vite. Tabulator и его типы закреплены в lockfile для экрана реестра C-103. Макеты экранов и токены дизайн-системы относятся к C-003.

## Запуск

Установите Node.js 22.18…22.x или 24 и новее. Используйте команды установки и запуска из каталога `web/`.

```shell
npm ci
npm run dev
```

Откройте адрес из вывода Vite. В режиме разработки заглушка отдаёт через API 10 000 строк реестра, страницы по курсору, справочники и ошибки. Изменения хранятся до перезапуска процесса Vite.

Для работы с LOCALAI запустите сервер из корня репозитория, подставив путь к своей тестовой базе. В новой базе пользователей нет: сначала создайте администратора.

```shell
python -m server.admin --db base.sqlite3 create-admin --login admin --name "Фамилия И. О."
python -m server --db base.sqlite3
```

Интерфейс открывается экраном входа. Сессия хранится в cookie `HttpOnly`: скрипт страницы её не видит, а клиент API отправляет запросы с `credentials: 'same-origin'`. Ответы `401` с кодами `auth_required`, `session_invalid` и `session_expired` возвращают на вход, `403 password_change_required` открывает смену временного пароля. Логика — в [src/session.ts](src/session.ts). Заглушка режима разработки начинает с выполненным входом демонстрационного администратора; после «Выйти» вход принимает любой непустой пароль.

В другом терминале из `web/` запустите Vite с прокси. По умолчанию прокси передаёт `/api/v1` на `http://127.0.0.1:8730`. Для другого адреса задайте переменную `LOCALAI_API_URL`.

```shell
npm run dev -- --mode server
```

## Маршруты и сборка

Оболочка использует клиентскую маршрутизацию через History API. Для списка разделов, прямых ссылок и кнопок «назад» и «вперёд» достаточно браузера и небольшого модуля маршрутов. Ctrl+K открывает клавиатурный переход к разделам. Места для профиля и задач находятся в верхней панели.

`npm run build` создаёт статический `web/dist/` после установки зависимостей. Браузер запрашивает API на том же адресе, с которого открыта оболочка. При раздаче через LOCALAI (K-106) HTML-адресам нужен fallback на `index.html` после обработки API и статических ресурсов. Неизвестный адрес показывает ссылку на реестр. Шрифты Inter для латиницы и кириллицы и значки находятся в проекте. Лицензия шрифта копируется в сборку.

## Клиент API

Вызовы структуры, реестров и записей идут через `src/api/client.ts`. Типы маршрутов и тел запросов генерируются из локального OpenAPI. Формы успешных ответов и фильтров берутся из [описания API](../docs/contract/api-v1.md) и [языка запросов](../docs/contract/query-language.md).

При создании и правке клиент добавляет UUID в `Idempotency-Key`. При сетевом сбое он один раз повторяет запрос с тем же телом и ключом. Правка отправляет `expected_version`. Ошибки API доступны как `ApiError` с кодом, сообщением, HTTP-статусом, полем и подробностями.

## Администрирование C-201

В режиме `npm run dev -- --mode server` перейдите в «Администрирование». Раздел доступен пользователям с `admin` в ответе `/auth/me`. Он содержит пользователей, роли с матрицей прав и разрешённые адреса. Экраны используют токены C-003. Заглушка C-002 предназначена для реестра, входа и клиентских ошибок; административные сценарии проверяются на LOCALAI.

Создание пользователя и сброс пароля открывают окно с временным паролем и копированием. После закрытия пароль удаляется из страницы. Если ответ с паролем потерян, повтор запроса возвращает пользователя без пароля, а строка пользователя предлагает сбросить его снова.

Матрица показывает выдаваемые действия и подписи из `/auth/permissions`. Общая строка действует во всех реестрах. Изменения показаны перед отправкой всей матрицы. Права на поля и документы сохраняются при изменении разделов и реестров. Право `purge` появляется вместе с каталогом K-103 из PR #19. Снимки экрана сделаны при подключении к этому серверу. [Пользователи](screenshots/admin-users.webp), [матрица прав](screenshots/admin-permissions.webp), [разрешённые адреса](screenshots/admin-networks.webp).

`npm run test:browser` самостоятельно запускает настоящий сервер на временной базе C-101 с 10 000 записей и случайным паролем. Python с зависимостями проекта должен быть доступен командой `python` или через `LOCALAI_TEST_PYTHON`. Переменная `LOCALAI_TEST_SERVER_ROOT` позволяет проверить интерфейс с другой рабочей копией сервера. Для снимков задайте каталог `LOCALAI_SCREENSHOTS`. Приёмочный сценарий использует собранные статические файлы через локальный прокси, cookie сессии остаётся `HttpOnly`.

## Локальные проверки

```shell
npm run check
npm run test
npm run build
```

Из корня репозитория `python -m tools.check` выполняет проверки Python и OpenAPI, а при наличии Node.js добавляет `npm run check` и `npm run test` в `web/`.

`npm run test:browser` запускает Chromium локально. Можно установить его командой `npx playwright-core install chromium --only-shell` или указать путь к установленному Chromium в `CHROMIUM_EXECUTABLE`. Для проверки оболочки с внешним сервером задайте `LOCALAI_API_URL`, `LOCALAI_LOGIN` и `LOCALAI_PASSWORD`. Без этих переменных оболочка проверяется на автоматически созданной временной базе. Браузерный сценарий входит через экран входа, читает состояние API и список реестров и выходит.

# Интерфейс и макеты LOCALAI

## Макеты C-003

Откройте [реестр](mockups/registry.html), [инспектор записи](mockups/inspector.html) или [карточку ККС](mockups/kks.html) из локальной копии репозитория. Страницы работают напрямую через `file://`. Кнопка темы находится справа в верхней панели. В реестре есть переключатель «Плотный / Свободный». Ссылки между экранами сохраняют настройки.

Во всех трёх макетах показан один пример для объекта `10LAC10AP001`. Реестр выводит до 50 строк одной страницы из 10 000 демонстрационных записей. Поиск, фильтр, страницы и разрешение конфликта работают на данных макета. Снимки обеих тем и двух плотностей реестра находятся в [mockups/screenshots/](mockups/screenshots/).

[Токены](src/tokens.css) задают палитру, шрифт, отступы, радиусы, тени и размеры ячеек. Плотный режим задаёт высоту строки 33 px, свободный — 46 px. Inter для латиницы и кириллицы находится в проекте вместе с [лицензией](public/licenses/Inter-OFL.txt).

Названия описывают компоненты для реализации в C-103 и последующих задачах. В статических макетах показаны их варианты и состояния.

## Каркас приложения

Каркас C-002 использует Svelte 5, TypeScript и Vite. Tabulator и его типы закреплены в lockfile для экрана реестра C-103. Макеты экранов и токены дизайн-системы относятся к C-003.

## Запуск

Установите Node.js 22.18…22.x или 24 и новее. Используйте команды установки и запуска из каталога `web/`.

```shell
npm ci
npm run dev
```

Откройте адрес из вывода Vite. В режиме разработки заглушка отдаёт через API 10 000 строк реестра, страницы по курсору, справочники и ошибки. Изменения хранятся до перезапуска процесса Vite.

Для работы с LOCALAI запустите сервер из корня репозитория, подставив путь к своей тестовой базе.

```shell
python -m server --db base.sqlite3
```

В другом терминале из `web/` запустите Vite с прокси. По умолчанию прокси передаёт `/api/v1` на `http://127.0.0.1:8730`. Для другого адреса задайте переменную `LOCALAI_API_URL`.

```shell
npm run dev -- --mode server
```

## Маршруты и сборка

Оболочка использует клиентскую маршрутизацию через History API. Для списка разделов, прямых ссылок и кнопок «назад» и «вперёд» достаточно браузера и небольшого модуля маршрутов. Ctrl+K открывает клавиатурный переход к разделам. Места для профиля и задач находятся в верхней панели.

`npm run build` создаёт статический `web/dist/` после установки зависимостей. Браузер запрашивает API на том же адресе, с которого открыта оболочка. При раздаче через LOCALAI (K-106) HTML-адресам нужен fallback на `index.html` после обработки API и статических ресурсов. Неизвестный адрес показывает ссылку на реестр. Шрифты Inter для латиницы и кириллицы и значки находятся в проекте. Лицензия шрифта копируется в сборку.

## Клиент API

Вызовы структуры, реестров и записей идут через `src/api/client.ts`. Типы маршрутов и тел запросов генерируются из локального OpenAPI. Формы успешных ответов и фильтров берутся из [описания API](../docs/contract/api-v1.md) и [языка запросов](../docs/contract/query-language.md).

При создании и правке клиент добавляет UUID в `Idempotency-Key`. При сетевом сбое он один раз повторяет запрос с тем же телом и ключом. Правка отправляет `expected_version`. Ошибки API доступны как `ApiError` с кодом, сообщением, HTTP-статусом, полем и подробностями.

## Локальные проверки

```shell
npm run check
npm run test
npm run build
```

Из корня репозитория `python -m tools.check` выполняет проверки Python и OpenAPI, а при наличии Node.js добавляет `npm run check` и `npm run test` в `web/`.

`npm run test:browser` запускает Chromium локально. Можно установить его командой `npx playwright-core install chromium --only-shell` или указать путь к установленному Chromium в `CHROMIUM_EXECUTABLE`. Для прогона сценария через прокси запустите LOCALAI и укажите `LOCALAI_API_URL`, в том числе при стандартном порте. Браузерный сценарий читает состояние API и список реестров.

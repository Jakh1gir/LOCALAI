# Чтение документов LOCALAI

Исполнитель `python -m vision --config <файл>` работает постоянно и опрашивает очередь API v1. Для него создайте в администрировании LOCALAI отдельную роль с разделом **«Фоновые задачи: выполнять»** и пользователя с этой ролью. Войдите один раз и смените временный пароль. У каждого одновременно работающего экземпляра должен быть свой логин: сервер связывает аренду с исполнителем по логину.

## Запуск

Из корня проекта в окружении Python 3.13 установите `python -m pip install -r vision/requirements.txt`. Подготовьте каталог Tesseract с файлами `rus.traineddata` и `eng.traineddata` из набора `tessdata_fast`. Для работы без интернета колёса Python и обе модели переносятся вместе с установочным комплектом. [Модели Tesseract](https://github.com/tesseract-ocr/tessdata_fast)

Параметры задаются в локальном JSON. Пример для процесса рядом с сервером:

```json
{
  "url": "http://127.0.0.1:8765",
  "login": "vision-worker",
  "password": "<постоянный пароль служебной учётной записи>",
  "tessdata": "C:/LOCALAI/tessdata",
  "cache": "C:/ProgramData/LOCALAI/Vision/cache"
}
```

Укажите фактический порт сервера. Для сетевого режима используйте HTTPS и при необходимости поле `ca` с путём к доверенному сертификату в PEM. Сессия хранится в памяти. При истечении сессии исполнитель повторно входит в API. Ограничьте права ОС на конфигурацию и кеш: в них хранятся пароль и текст документов. [Установка службы Windows](../packaging/README.md)

## Какие данные появляются в документе

| Формат | Результат |
| --- | --- |
| PDF с текстовым слоем | Текст по физическим страницам, начиная с 1 |
| PDF со сканами | OCR для страниц без текста, включая такие страницы в смешанной книге |
| PNG, JPEG, TIFF, BMP | Русский и английский OCR по кадрам, номер и нормированная область распознанного текста |
| DXF | Надписи по имени листа, включая текст во вставках блоков и многострочный текст |

Процесс получает только задачи `document.read` для `vision`. Перед разбором сверяется SHA-256 скачанного файла. Индекс, фрагменты и ссылки на страницы создаёт сервер при сдаче результата. Распознавание выполняет отдельный постоянный процесс с загруженными моделями. Кеш успешного разбора различает версию алгоритма, библиотек и моделей. Кеш можно удалить при остановленной службе.

Пустая очередь опрашивается каждые 4 секунды. Битый PDF получает ошибку чтения сразу, временные ошибки обрабатываются по числу попыток сервера. Замена или архивирование документа отменяет старую задачу. Для многостраничного скана, обработка которого превышает 9 минут, исполнитель сообщает о превышении времени. Одна минута оставлена на завершение аренды. [Запрос на продление аренды](../docs/requests/007-claude-vision-lease.md)

## Локальная проверка

Установите зависимости сервера и тестов, зависимости из `vision/requirements.txt` и `reportlab` для генерации PDF. Укажите каталог двух моделей переменной `TESSDATA_PREFIX`. Сценарии используют временную базу, настоящий HTTP-сервер, служебную роль и вымышленные документы:

```shell
python -m pytest -s tests/e2e/test_vision_reader.py
```

Замер PERF-12 начинается перед загрузкой текстового PDF на 50 страниц и заканчивается получением найденного фрагмента страницы 50. Во время чтения сценарий параллельно запрашивает карточку по HTTP. В замере исполнитель уже запущен, задача забирается сразу. В обычном режиме перед захватом добавляется ожидание ближайшего опроса.
